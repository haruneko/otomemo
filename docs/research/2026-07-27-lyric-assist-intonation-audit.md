# イントネーション表示の齟齬監査（Opus・一次情報裏取り済み）

- 日付: 2026-07-27
- これは何: モックv5のイントネーション表示にオーナーが「どこがVOICEVOXを参考にしてるのかわからない」と強い不満→Opusエージェントがモックの実レンダとVOICEVOX公式資料（GitHub `public/howtouse.md`＋`public/res/` の一次画像）を突き合わせた監査の全文保存。**モック修正はまだ適用していない**（オーナーがセッションのリセットを宣言・次セッションが本docの仕様から再開する）。
- 経緯の要点: メインセッション（当時）が2度の委譲パッチと1度の直接修正で直せず。振幅を潰した13pxの飾り下線になっていた＋参照する欄自体を取り違えていた。

## 一次情報でわかった重大な前提のズレ

公式マニュアル（howtouse.md L141）:「**「イントネーション」をクリックして現れる縦線のバーを上下させる**ことで抑揚を表現できます」。

つまり **VOICEVOXの「イントネーション」欄は折れ線ではなく、モーラごとの縦スライダー**（細い縦トラック＋丸ノブ、カナは真下）。折れ線（段状のグラフ）が出るのは**「アクセント」欄**のほう。モックは「VOICEVOX想定」と銘打って折れ線を描いており、**参照先の欄そのものを取り違えている**。

※オーナーが最初に提示したスクショ（VOICEVOX下部）の見た目＝カナの箱の上に段状の線。どちらの欄・どちらの様式を採るか（縦スライダー案A / 折れ線案B）は**未裁定**＝次セッションでオーナーに確認。

## 齟齬リスト（モック実体: mockups-v5.html L165-171, L608-640 時点）

モック側の実体:
- `.cmp` ブロック全高 **34px**、高低線SVG `height=13`、カナ枠 `top:14px height:18px`
- 折れ線 path の y値は **3〜10 のみ＝振幅7px**、モーラ区画 18px間隔・幅16px
- 多段版の y列 = `10,3,4,4,5,6,9,10` → 隣接差は**大半が1px**
- 線 `stroke:#9aa0aa; stroke-width:1.3`（無彩色ヘアライン）

1. **参照した欄が違う**（最重要）。VOICEVOXのイントネーション欄＝縦スライダー＋丸ノブ。モック＝折れ線。ノブが無く「掴んで上下させる欄」に見えない。
2. **絶対的な高さが1/6〜1/20**。VOICEVOX: トラック高 約106px（既定）〜約270px（拡張時）。アクセント欄の縦ガイドでも約75px。モック: **13px**。
3. **画面占有率が1桁違う**。VOICEVOXは下部ペインがウィンドウの**約38%**（上端ドラッグで拡張可）。モックは800px画面中13px＝**1.6%**。
4. **段差が見えない**。VOICEVOXアクセント欄: モーラ間隔56pxに対し高低差約57px（比1.0）。モック: 間隔18pxに対し振幅7px（比0.39）、多段の実隣接差は**1px（比0.06）**＝スマホ実機では消える。
5. **モーラ区画が無い**。VOICEVOXは各モーラに**破線の縦ガイド**をグラフ底まで引く。モックはカナの角丸ボックスだけで、線とボックスの縦の連結が無く13pxのSVGが宙に浮く。
6. **折れ線のシルエットが違う**。VOICEVOX: 低→高の遷移がモーラ1つ分をかけた**長い斜線**＝台形/山型。モック: 平坦16px＋2px幅のほぼ垂直な微段＝平らな帯。
7. **アクセント句の区切りがほぼ不可視**。VOICEVOXはグラフ上に**句の横バー＋丸ノブ**・区間クリックで青ハイライト。モックはカナ枠の右線の色を変えるだけ。
8. **色・可触性の信号が無い**。VOICEVOXは彩度の高い緑で「操作できる」を示す。モックは無彩色ヘアライン。しかもモック内の裁定注記自体が「細い無彩色」と明記＝**齟齬が設計文の段階で固定されていた**。

## 診断（一言）

**参照した欄を取り違えたうえ（イントネーション欄＝縦スライダー、折れ線はアクセント欄）、縦を1/6〜1/20に潰した**ため、VOICEVOXの「掴める縦バーが床から天井まで並ぶ1/3の欄」という一番目立つ特徴が全部消え、13pxの飾り下線になっている。

## 修正の具体仕様（360px幅・コンテンツ幅300px内・区画は音符矩形に縦揃え維持）

**A. 縦スライダー案（VOICEVOXイントネーション欄に忠実・監査の推奨）**
- 欄: グラフ領域 **72px**＋カナ行18px＝計90px（`.cmp{height:92px}`・SVG `height=72`）
- 各モーラ: 区画中心に**縦トラック幅2px を y=4〜68（64px）**。ノブ位置より上は `#3f454e`、下は色付き
- ノブ: **直径8pxの円**（トラック/ノブ比 64/8=8.0＝VOICEVOX同等）
- 値域: 最小y=64・最大y=8＝**振幅56px**。隣接モーラの最小可視差は**6pxを下限**にクランプ
- 色: ノブとトラック下部に彩度のある1色（例 `#7fc0e8`）。無彩色ヘアラインは撤回
- カナ: トラックの真下 y=74〜92。角丸ボックスは外すか枠線を `#2a2e35` へ落とす

**B. 折れ線案（アクセント欄ふう・オーナー提示スクショの見た目に近い）**
- 欄の高さ **72px**・振幅 y=8〜64 の**56px**・隣接差の下限6px
- 各モーラに**破線の縦ガイド**（`#3f454e; dasharray 2 3`）y=8〜68
- 折れ線: **stroke-width 2px**・遷移は**区画中心→次の区画中心を結ぶ斜線**（垂直の微段は廃止）
- 上端 y=2 に**アクセント句バー**: 句の範囲に水平線2px＋中央に丸ノブ7px。句が変わる所で線を切る

**C. 2段/多段の並置の扱い**
- 上下2段×各90px＝約200px（画面の25%）。比較目的が済んだら**どちらか1つに畳む**前提。両方常設なら各56px（振幅42px）が下限＝それ未満は齟齬2・4が再発。
