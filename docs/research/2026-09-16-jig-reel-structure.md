# アイリッシュのジグとリールの旋律の構造（ケルト白紙設計の前の研究）

## 要約（先に読む）
1. **本物らしさの芯（仮説）**＝①部（8小節）ごとに1つの「軸の音」（主和音の音＝主音・5度・3度のどれか）へ**2小節おきに帰る**こと（帰ったあとは違う続き）②8分が途切れずに流れ、止まるのは句の節目だけ ③1〜2小節の音型（音階の走り・分散和音の跳ね・隣の音を回る・同じ音の打ち直し）の反復と変奏 ④リールでは弓のつなぎ（slur）でアクセントが裏拍へずれること。
2. phrase_maker の耳の記録で「本物と明確に差が出た」のは①（「軸が無い」）とリールの④（slur ゼロで「つるつる」）。旋法を守る・終止を主音/5度に置く・AABB は**入れても本物に聞こえなかった**＝必要条件どまり。
3. **ジグとリールの差**＝拍の束（6/8 の3個ずつ vs 2/2 の4個ずつ＝大拍2つ）・同じ音の使い方（ジグは束の頭の長短に同音が多い／リールは拍頭でない位置の打ち直し）・軸の強さ（リールの方が強い）・ジグの長短の揺れ／リールの前へ転がる流れ。
4. **音符で書けるもの**＝旋律の音と音価・ジグの「4分＋8分」の長短（作曲上の打点）・同音の打ち直し・音符として書いた3連符・slur の**範囲**（どの音をひとまとまりにするかという句読点）。
5. **音符で書けない（DAW の領分）**＝cut・tap・roll・cran・slide の実際の鳴り方（長さ・音量）・8分の微妙な長短の揺れ・弓の強弱の山谷。記号として「ここに roll」と印を置くことはできる。
6. **統計で取るもの**＝拍位置別の音程分布・軸の帰還率（2小節おき）・同音の位置分布・句の終わりの音の分布・音域と部ごとの重心・旋法の比率・音型の種類（音程の形だけ）の頻度。出どころ＝O'Neill's 1001（folkies/oneill の ABC）・The Session のデータダンプ（ODbL）・IrishMAN。**旋律そのものは保存しない**。
7. **設計の前に決めること**＝作業上の定義（ダブルジグ／リールだけ・AABB 32小節）・置き場（主旋律＝前景）・slur を「楽譜の情報」に含めるか・耳で先に確かめる論点（軸の帰還だけで差が出るか等、§7）。

凡例：**[外]**＝外部出典（URL）／**[pm]**＝phrase_maker の記録（`ファイル:行`・パスは `~/projects/phrase_maker/` 起点）／**[推測]**＝本文書の見立て。一次資料＝教本・奏者本人の解説・データそのもの。二次資料＝解説サイト・百科事典・phrase_maker の要約経由のもの。

## 1. 定義と構造

| | ダブルジグ（以下ジグ） | リール |
|---|---|---|
| 拍子 | 6/8（1小節＝8分3個×2束） | 4/4 と書くが感覚は 2/2（大きな拍が2つ・各4個の8分） |
| 形 | AABB・各部8小節＝4+4 | 同じ（ただし素朴な AABB から外れる曲が多い） |
| テンポ | 付点4分でおよそ 100〜120 前後（[推測]・セッションの速さで幅が大きい） | 2分音符 ≈ 90〜115（8分で毎分約400個前後） |
| 手触り | 跳ねる・長短の揺れ | 途切れない流れ・前へ転がる |

- [外・二次] ジグは8小節の部が2つ、各部を繰り返して AABB、全体を少なくとも2周。「ジグ」とだけ言えば普通はダブルジグ＝3個ずつの束が2つ。束の頭が長く強い。<https://www.tradschool.com/en/irish-music/tune-types-in-irish-traditional-music/>・<https://folkworks.org/article/guide-to-irish-tune-types/>
- [外・二次] リールは 2/2 の感覚で、AABB＝4小節句×2 の部が2つ。<https://folkworks.org/article/guide-to-irish-tune-types/>・<https://www.irishtune.info/rhythm/reel-structure.html>（索引上、約44%のリールは素朴な AABB から外れる＝[pm] `docs/research/celtic/02-reel-idioms.md:18` 経由）
- [外・二次] リールのテンポ（2分≈90-115）：[pm] `docs/research/celtic/02-reel-idioms.md:19` 経由 <https://thesession.org/discussions/31896>・<https://www.drewvervan.com/?page_id=80>（本文書では原典を再確認していない）
- **句の型**：[外・二次] 4つの4小節句のうち、**3つ目が最も型から離れ、4つ目が型に戻る**ことが多い（問いと答え）。[pm] `02-reel-idioms.md:24` 経由 FolkWorks。
- **終止**：部の終わり（8小節目）は主音、4小節目は主音以外（5度など）で半ば開いて終わるのが一般形 [推測・一般の民謡の句構造。phrase_maker で「終止を主音/5度」は機械的には 8/8 で満たしたが、本物らしさには足りなかった＝[pm] `experiments/celtic/gen2/LISTEN.md`（metrics 表 cadence hit 1.00）と同 `docs/research/celtic/05-axis-tone.md:3-4` の耳]。ジグでは部の最後の小節が「4分＋8分」×2 など長い音で止まる形が多い [推測]。

## 2. 旋律の運び

### 2.1 旋法
- [外・二次] Breathnach『Folk Music and Dances of Ireland』の数字として：長調（アイオニアン）60%超・ミクソリディアン約15%・ドリアン10%強・エオリアンが最少。<https://thesession.org/discussions/39387>（本の原文は未確認）・<https://en.wikipedia.org/wiki/Traditional_Gaelic_music>
- [外・二次] セッションでよく使う調は D・G（長調）、A・E ドリアン、A・D ミクソリディアン。臨時記号は少ない（楽器が D/G の全音階だから）。
- [推測] 旋法の比率はジグ／リールで違う可能性があるので、§6 の統計で種類別に取る。

### 2.2 音域（楽器ごと）
- [推測・楽器の一般知識、出典で再確認を要す] ティンホイッスル（D管）とフルート（木製 D 管）は低い D から2オクターブ上の D 手前まで（ホイッスルは記譜の1オクターブ上で鳴る）。**低い D より下が無い**ので、伝統曲は下の D を底にした音域に収まりやすい。フィドルは下の G まで出るが、合奏の共通語として D〜B（2オクターブ弱）に収まる曲が多い。
- [外・二次] 旋律の音域は1オクターブ半以内が多い：[pm] `02-reel-idioms.md:25` 経由 <http://www.braccio.me/session/FieldGuide.pdf>
- [推測] B 部は A 部より音域の重心が上がる曲が多い（[pm] `05-axis-tone.md:68` の実測所見「B部は音域が上がるのに伴って軸も上の和音構成音に移る」と一致）。

### 2.3 軸の音（ドローン・反復される要の音）
- [pm・実測] O'Neill's（ダブルジグ367・リール351）のアンカー（小節頭と半小節頭）の列で、**2小節おきに同じ音へ帰る**のが偶然より明確に多い。リールは2小節おきの帰還 45%（偶然の約2倍）、ジグ 26%。隣のアンカーでの連打は偶然以下＝居座るのではなく**帰ってくる**。`docs/research/celtic/05-axis-tone.md:12,36,39,84`
- [pm・実測] 帰還の約7割は丸写しの反復ではなく、同じ音に帰ってから**違う続き**をやる（ジグ68%・リール72%）。`05-axis-tone.md:13`
- [pm・実測] 軸の正体は部ごとに1つ、主音29/33%・5度25/21%・3度17/19%（ジグ/リール）で約7割。`05-axis-tone.md:14,63`
- [外・二次] 近い概念＝詠唱の reciting tone（旋律が戻り続ける構造的な1音）<https://en.wikipedia.org/wiki/Reciting_tone>、アイルランド／スコットランドの double tonic（主音とその全音下の和音の交替）<https://en.wikipedia.org/wiki/Double_tonic>。
- [推測] フィドルの開放弦（D・A）やパイプのドローンが「軸を耳に残す」働きをしている可能性。ただし上の実測は旋律だけで軸が出ている＝伴奏に頼らず旋律内に作るべきもの。

### 2.4 同じ音の反復
- [pm・実測] 装飾記号を剥がした素の音符でも、同じ音の連続はジグ99%・リール98%の曲に出る。100音あたりジグ11.1・リール7.1。ジグは2連・3連、リールは2連・4連が多い。`docs/research/celtic/04-same-pitch-repetition.md:11,36-40`
- [pm・実測] 置き場所が違う：生成器のリールの同音は91%が拍頭（アンカー）だったが、本物はそこに13%しか置かない＝「リールはよくない」の説明。`04-same-pitch-repetition.md:102-103`
- [推測] ジグの同音は「束の頭の長い音を2つの8分で打ち直す」形、リールの同音は拍の途中で打ち直して流れを保つ形、と読める。

### 2.5 分散和音と音階進行・跳躍
- [外・二次] 素材は音階の上り下りと分散和音の音型。[pm] `02-reel-idioms.md:25` 経由 Field Guide。
- [pm・監査] ジグで跳躍が減り順次進行が増えた版が良く聞こえた（跳躍24→17・順次26→36）。「小節頭で根音を踏む率」は品質と逆相関。`docs/poc/AUDIT-jig-musical.md` §0（2・3項）
- [pm・診断] 弱拍で毎音上下を独立に引くと「音階の中を意味もなく彷徨う」。人の旋律は同じ向きに数音続く走りを持つ。`docs/research/celtic/01-jig-random-walk-diagnosis.md:4,33-35`
- [推測] 跳躍は分散和音の中（3度・4度・6度）がほとんどで、大きな跳躍の後は逆向きの順次進行で戻る、という一般の旋律原則がそのまま当てはまるはず。比率は §6 で実測する。

### 2.6 句の頭と終わり
- [推測] 句の頭は弱起（ジグは8分1個、リールは8分1〜2個）を伴うことが多い。句の終わりは長い音（ジグ＝4分＋8分、リール＝4分や付点4分）で止まり、次の句への弱起で流れを戻す。§6 で弱起の有無・終わりの音価を取る。

## 3. リズム：作曲上の打点か、演奏上の揺れか

| 特徴 | 分類 | 根拠 |
|---|---|---|
| ジグの束（3個ずつ）と、束の頭を長くする「4分＋8分」の形 | **作曲上の打点**（楽譜に書かれる音価） | 伝統の楽譜でも 4分＋8分 と 8分3個 が書き分けられる |
| ジグの 8分3個 の「長め・短め・普通」の揺れ（lilt） | **演奏上の揺れ** | [外・二次] 付点8分-16分-8分 くらいの感じと説明される＝記譜は均等8分 <https://www.tradschool.com/en/irish-music/tune-types-in-irish-traditional-music/> |
| リールの8分の微妙な長短 | **演奏上の揺れ**（固定比のスウィングではない） | [pm] `02-reel-idioms.md:34` 経由 Soundbrenner <https://www.soundbrenner.com/blogs/articles/reel-rhythm> |
| リールの大拍（1・3拍目）のアクセント | 拍子そのもの（書かない） | 同上 |
| リールの 2・4 拍目への押し出し（slur 明けのダウンボウ） | **弓のつなぎの結果**。つなぎ方（範囲）は書ける／強さは演奏 | [pm] `02-reel-idioms.md:32` 経由 <https://philberthoud.com/bringing-irish-reels-to-life-bowing/> |

→ Otomemo の決まり（ノリはスコアに焼かない）に照らすと、スコアに入るのは「音価としての 4分＋8分」と「句読点としてのつなぎの範囲」まで。揺れの比率はスコアに入れない。

## 4. 装飾と弓づかい

| 名前 | 中身 | 判定 |
|---|---|---|
| cut | 主音の直前の、上からの極短い装飾音（音程感は無い） | 位置の印は書ける／鳴りは**演奏（DAW）** |
| tap（strike） | 主音の直前に下の音を叩く極短の装飾 | 同上 |
| roll | 主音→cut→主音→tap→主音。長い音（リールの付点4分・同じ音の8分2〜3個／ジグの4分＋8分）を埋める | 「ここに roll」は書ける（ABC の `~`）。**中身は演奏**。**置ける土台＝長い音や同音の連続は作曲側で作る** |
| cran | パイプ由来。低い D など roll ができない音で cut を重ねる | 演奏（DAW） |
| slide | 下（または上）の音から指をずらして主音へ滑る・聞き取れる | 演奏（DAW） |
| 弓の3連（treble） | 同じ音を3回短く刻む。1拍を占める。最後の弓は次の音へつなぐのが原則 | **音符で書ける**（同音の3連符）。ただし強さの形は演奏 |
| slur（弓でつなぐ） | 弓を返さず2〜4音を1弓で。1拍半のつなぎを小節線またぎ・小節の中央またぎに置き、明けの弓を 2・4 拍目へ | **範囲は書ける**（句読点）／強弱の山谷は演奏 |

出典：[外・二次] <https://www.tradschool.com/en/about-irish-music/ornamentation-in-irish-music/>・<https://oaim.ie/tin-whistle/tin-whistle-foundations/>・<https://thesession.org/discussions/27180>・<https://violinspiration.com/ornamentation-in-irish-music/>。roll の定位置は [pm] `02-reel-idioms.md:39` 経由 <https://learntinwhistle.com/lessons/tin-whistle-rolls/>・<https://thesession.org/discussions/29336>。弓の3連と最後をつなぐ原則は [pm] `docs/poc/AUDIT-reel-ornament-notevalue.md:72,158` 経由 Alden Robinson・Peghead Nation。Sligo 風は長い slur＋裏の強調、Donegal 風は roll の代わりに弓の3連：[pm] `02-reel-idioms.md:33` 経由 <https://www.tradschool.com/en/irish-music/regional-styles-of-irish-traditional-music/>。

**リールで slur が芯と言われた理由**：
- [pm] 装飾以外の122音が全部同じ長さ・同じ切れ方で、つなぎが1つも無かった。「引っかかりが無くてつるつる」は装飾6個では埋まらず、**弓のつなぎ方が一番大きな未着手のレバー**と判定。`docs/poc/AUDIT-reel-ornament-musical.md:145-152`
- [推測] リールは8分が均等に流れるので、どこで息をつくか（どこが強くなるか）の情報が音程と音価からはほとんど出ない。ジグは「4分＋8分」という音価の差が句読点の役を果たすが、リールではその役を slur が担っている。だから slur が無いとリールだけが平板になる。

### 6.2 取るべき統計（旋律の並びを残さない形で）
1. **拍位置別の音程分布**：ジグ6位置・リール8位置ごとに、直前の音からの音程（半音数）のヒストグラム。
2. **順次・分散和音・跳躍の比率**と、跳躍の後の戻り方（逆向き順次の率）。
3. **軸の帰還**：2小節おき（lag）で同じアンカー音になる率・部ごとの最頻アンカー音の度数（主音/5度/3度…）の分布。
4. **同じ音の反復**：100音あたりの数・連続の長さ・拍位置の分布。
5. **句の終わり**：4・8小節目の最後の音の度数と音価の分布、弱起の有無と長さ。
6. **音域**：曲ごとの最高・最低（主音からの度数）、A 部と B 部の重心の差。
7. **旋法の比率**：品目別（ジグ／リール）。
8. **音型の種類**：1小節の「上下の向きの形」（例：上上上下…の符号列）や「和音音か経過音か」の類型の頻度。**音高そのものは捨て、形の種類の数だけ**残す [推測：ここがリテラルに近づく境目なので、種類の細かさはオーナー判断]。
9. **3つ目の句の離れ具合**：句どうしの類似度（1・2・4句と3句）。

取り方：ABC を読み、装飾記号（`~` `{}` 等）を剥がし、調号と臨時記号を反映して度数列へ直し、上の数値だけを書き出して元の列は捨てる（phrase_maker の 04・05 がこの手順で実測済み＝手順の前例）。

## 7. 設計の前に定義しておくこと（設計はしない）

1. **作業上の定義**：「ジグ」＝ダブルジグ（6/8）、「リール」＝2/2 の大拍で8分が流れる曲。シングルジグ・スリップジグ・ホーンパイプは範囲外。長さの基準＝AABB・各部8小節（4+4）。
2. **置き場**：主旋律＝前景（メロ側）。伴奏・ドローン・バンドは別の話。装飾と揺れは DAW 側＝Otomemo が出すのは音と音価まで。
3. **slur の扱い**：句読点（どこからどこを1まとまりにするか）を楽譜の情報として持つか、持たないか。リールの本物らしさの芯に関わるので要件の段で決める。
4. **roll の土台**：roll を置ける長い音・同音の連続を「作曲側で作る」ことまでを範囲とするか。
5. **統計の線**：§6.2 の 8（音型の類型）をどこまで細かく取ってよいか。
6. **耳で先に確かめる論点**（聴き比べの順）：
   - (a) 軸の帰還だけを入れた旋律と入れない旋律で、差が聞こえるか（H1 の単独効果）。
   - (b) リールで slur の範囲を付けた MIDI（DAW で弓の強弱を付けて鳴らす）と付けないもので差が出るか（H3）。＝スコア外の要素が芯なら、Otomemo で出す意味がどこまであるかの判断材料。
   - (c) ジグとリールで同じ骨組みを使い回して、束の大きさだけ変えたら本物に聞こえるか（共通の土台で足りるか）。
   - (d) 雑に打ち込んだ場合（音階内の8分の羅列）との差が出るか（phrase_maker から残す考え方の評価法＝`docs/research/2026-09-16-phrasemaker-ideas-to-keep.md`）。
