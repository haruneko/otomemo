# 作詞補助ツール — コンセプト

## 1. この道具は何か

作曲家が、自分の曲の歌詞とメロディを、出先の細切れ時間でもスマホから開いて書き足し、仮歌で鳴らして確かめるための道具。曲は最初から通しでは書かれず、詞もメロも穴だらけのまま進む（穴は最小1単語から、大きければ曲全体が斑）ので、その斑のどこからでも開けて、推敲のときだけ曲全体の歌詞を通して見られる。仕上げは別のDAWでやるので、この道具は仕上げの手前までを受け持つ（「デスクトップパソコンをことさらに意識せずスマホベースでどっちも。なぜなら仕上げはDAWとか別のもの使うから」）。

## 2. する道具・しない道具

### すること

- **どこからでも歌詞を書き足せる。** 曲先と詞先は1曲の中で往復し、「どこでも開くのが正しい」。メロディからも曲全体からも歌詞を直せる（「操作としてはメロディからも曲からも歌詞は修正したい」）。メロを単体で開いたときも詞が書ける。曲もセクションも無い思いつきはメモとして置ける。
- **穴だらけのまま置ける。** 詞側とメロ側は独立に欠け、両方空白の区間も普通にある。埋まっていない状態を異常として扱わない。「字余り」と「メロがまだ途中」は別のこととして区別する。
- **通しの推敲の面がある。** 「書くのは通しではない。ただし推敲は必ず通しでする」「音韻のチェックとかする以上、現状の歌詞全体はみえるべき」。見るものは選べるようにする（「だいぶうるさいかな？表示したいパーツを選べるようにしたり出来ない？？」）。
- **音韻とイントネーションの確認を機械が手伝う。** イントネーションは高い・低いの2段だけを見る。機械が読みや高低を間違えたら、人が手で直せる（「手で直せるがよいかと」）。
- **仮歌で鳴らして確かめられる。**
- **コピーと比較を強くする。** 2番は複製で作る（「複製でよくね？コピーとか比較とかを代わりに強くすればいい」）。1番と2番の差を見る面もほしい（優先度は未確定）。
- **発散の助けと収束の助けの両方を出す。** 「収束がありがたいからと言って発散の助力がいらないとは一言も言っていない。双方あるのが良い」。

### しないこと（理由＝オーナーの発言）

- **仕上げをしない。** 仕上げはDAWの仕事（「仕上げはDAWとか別のもの使うから」）。
- **意味と感情遷移に機械が踏み込まない。** 「音韻、イントネーションは機械が手助け可能、意味、感情遷移は踏み込むと破綻すると思う」。
- **喋らせない。** 音の高さの具体は扱わない（「高低のみを見るのでいいよ。喋らすのは主眼にないから」）。
- **完成品を出して終わりにしない。** 「作る努力の部分を人間から奪うと自作感がなくなるので、最後に選ぶのは人間にさせるべき」。
- **メロや歌詞が分かれるのを防がない。** 「アレンジは基本少しずつ違うもんだよ？」「過剰に分派が生まれるのを避けなくても良い」。分かれるのは作り方の自然な姿であり、防ぐ代わりにコピーと比較を強くする。
- **同じメロに複数の歌詞案を並べて管理しない。** ほぼしない、との発言による。
- **意味→音の順番を道具の構造に焼き付けない。** 「固定ではない、これは固定してはいけない」。

## 3. 「歌詞」「仮歌」「メロ」の関係

**歌詞の正データは、漢字仮名交じりの普通の文章である**（「歌詞の正データは漢字仮名交じりの普通の文章です」）。人が読み書きし、通しで推敲するのはこれ。

**かな書き（シラブル）は歌詞ではない。** 「かながきは仮歌のためにあるもの」＝歌詞をメロに乗せて鳴らし、確かめるために導かれる姿である。機械が読みやイントネーションを取り違えたら、人が手で直せる。「っ」「ー」にも音符を立てる。

**歌詞はメロに付く。** 「セクションではなく仮歌を入れるメロディにほしい。Sectionに歌詞ってなんか違和感がある」。メロを単体で開いても詞が書ける。ただし詞先ではメロの無い場所にも歌詞があるので、**メロの無い区間の歌詞は曲が持つ**。空のメロを勝手に置いてそこに入れることはしない——まだ無いものを在ることにする操作は、「ゴミが増えるのは嫌なので暗黙の操作はあまり増やさないでほしい」「実体を明確に作る合図なければ作られたくない」に反するため。曲もセクションも無い思いつきはメモでよい。

**メロと歌詞が不可分とは、置き場所の話ではない。** 「言い回しによって符割りで対応できなくて音符を減らす増やすするパターンがありえて、このパターンはメロディが派生する」＝言葉がメロを変え、メロが言葉を変える、という作り方の事実を指す。だからメロが分かれることを恐れない。2番は複製で作り、分かれた後はそれぞれが本物として扱う。

## 4. 体験として守る線

- **最後に選ぶのは人間。** 機械は候補と確認材料を出すところまで。
- **点数で優劣を付けない。** 韻やアクセントの理屈は、間違いに気づくための根拠であって、良し悪しを裁くものではない。
- **黙って実体を作らない。** 曲・セクション・メロを、明示の合図なしに道具が作らない。
- **普通の言葉で呼ぶ。** 比喩や強い名付けをしない（「強い言葉はいらない。イメージを誤るので」「内輪語になってない？？」）。穴は穴、斑は斑と呼ぶ。
- **埋まっていないことを咎めない。** 下書き・確定の区別のような「作者がわかる」情報ではなく、歌詞がない・メロがない・よく嵌っている、という状況が見えること。

## 5. コンセプトとして残る未確定

1. **歌詞を当てたとき、仮歌はどこまで自動でできるか。** オーナーは「メロディに対して歌詞を適用すると、符割りに基づいて仮歌用の歌詞が入ること」が最も正しいと言いつつ「だけどこれはできないんでは？」と保留している。どこで伸ばしどこで切るかを機械が決めてよいのか、人の判断なのかは未裁定（割付の手直しは「手でずらせたり自動符割りを見据えたうえでの最初は取り扱わなくて良い」＝先送りだが、後から足せる前提）。**これを決めると**、歌詞を書き直してから仮歌で確かめるまでに人の手作業がどれだけ残るか＝この道具の中心の往復の手数が決まる。
2. **元のメロを直したとき、複製した先にどこまで及ぶか。** 「メロがわかれるのは良い」と「軽微なら変化の適用はされたい」が同居しており、「軽微」の線引きは未裁定。**これを決めると**、複製した1番と2番が黙って別々のものになるのか、細く繋がったままなのかが決まり、「コピーと比較を強くする」の中身（比較の面で「同じメロだった」ことをどう扱うか）が決まる。
3. **通しの推敲の面に何が見えるか。** 推敲で見るのは意味・感情遷移・音韻・イントネーションの4点だが、機械が踏み込まない意味と感情遷移を、人が確かめるために面に何を出すか（人が書いたメモを見せるのは踏み込みか）は未定。オーナー自身「一回それで形見ましょう、でてきたのをこの部分でひっくり返したらごめんね」と仮置きの態度。**これを決めると**、4点のうち道具の画面が受け持つ範囲と、人が頭の中でやる範囲の線が決まる。
4. **発散の助けの具体。** 「双方あるのが良い」とまでは確定だが、作詞での発散として何を出してほしいか（語の候補か、韻か、「ここに『通り過ぎる』という言葉で、3文字、このアクセント」というパズルの答えか）は語られていない。**これを決めると**、機械が出す候補の種類と、それを出してよい場面が決まる。
5. **1番と2番の差を見る面の優先度。** 「ほしい。優先度は高いかはわからない」。**これを決めると**、最初に作る範囲に比較を含めるかが決まる。複製の運用は「代わりにコピーとか比較とかを強くすればいい」が前提なので、比較が無いままでは複製で進める作り方が成り立つかを確かめられない。
