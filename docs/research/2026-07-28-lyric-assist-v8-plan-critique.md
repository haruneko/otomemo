# v8差分計画の批判（実行前に潰すべき欠陥）

## 1. `spans`（表記文字→モーラ範囲）は書いてある方法では作れず、定義自体が閉じない【最重量・工程0が止まる】

- **何が問題か**: 計画は spans を「bakeが機械生成」とするが、accent.py はアラインメントを返さない（実走で確認: 出力は moras/hl/phrases のみ）。生成手段が存在しない。
- **どこか**: §7工程0「`spans`（表記文字→モーラ範囲。bakeが機械生成）」、§8検証2。
- **何が起きるか**:
  - 「今日」→ kyo-o（実測）。2文字↔2モーラだが**文字単位の対応に根拠が無い**（今→きょ？日→う？）。v7実在句「きょうのよていを かみにかく」の表記化で確実に踏む。「文字→モーラ範囲」という定義は熟字訓で閉じず、検証2「全句で閉じる」は満たしようがない。
  - さらに「予定」→ yo-te-**e**（実測・長音化）。v7の絵は「よてい」。hyoki を原本にした瞬間、**モーラ行に表示する かな文字の出所が計画のどこにも無くなる**（accent.py はローマ字。逆変換は「きょ お/きょ う」で一意でない）。
  - yomiSrc 使用時（hyoki「にわへ」＋yomiSrc「庭へ」）、spans をどちらの文字列に張るか未定義。枚9（新枚B）はこの状態そのものを描く枚。
- **直し方**: span を「表記の区間↔モーラ区間」の多対多に改め、生成方法（pyopenjtalk の形態素読みを使う等）・モーラかな表示の源（feed文字列側）・yomiSrc時の張り先・閉じない場合の逃げを計画本文に書いてから工程0へ。

## 2. 既定でメロ帯を畳むと「メロの空き」が既定の姿から消える＝裁定2違反

- **何が問題か**: §3-2の「出す」列挙は「まだ何も無い区間」枠・「あとN音」「字余りN」・予定チップのみで、**メロの空きの事実が無い**。
- **どこか**: §3-2。
- **何に反するか**: 裁定2原文「そもそも歌詞がないメロがないのかなど」。v7でメロ空きは「帯の無い行」で見えていた（枚1のCメロ・2番サビ等）。帯を畳むと「ざっしをとじて（メロなし）」と「あさおきて（メロあり）」が既定で同じ表記の行になり、メロの穴の所在が通し推敲から消える。
- **直し方**: 既定の「出す」に「メロの空きN句」チップを明記。

## 3. 割当②の対象（空きの枠）が既定から消えるのに「割当文面は変えない」と宣言＝批判2の再発

- **何が問題か**: 空きマスの列を「詞の空きN音」チップ1個に畳むと、割当②「空きの枠をタップ＝小フォーム」のタップ対象が既定の姿に存在しない。§3-2は③④の成立だけ書き、②に触れていない。
- **どこか**: §3-2「割当③④は帯オフのときも…成立。割当文面は変えない」、§7「B・Dへは割当①〜⑤の文面を同一文で渡す」。
- **何が起きるか**: Bの枚1（チップしか無い絵）とDの枚14（「空きの枠をタップ」の文面）が乖離したまま工程2へ届く。前回の批判2「同じ操作に別の意味・解消規則なし」と同じ穴。
- **直し方**: 「畳み時は②の対象＝詞の空きチップ」を計画本文で確定し、B/Dに同一文で渡す。

## 4. 音数系の黄ドット新設が、自ら掲げた「新類型の黄を増やさない」と矛盾

- **何が問題か**: §1-4は音数の食い違いに「行末ドットは黄（marks.jsに音数判定を追加）」を足すが、§4差し戻し5は暫定案Bの採用理由を「**裁定前に新類型の黄を増やさない側**」と説明している。同じ計画の中で理由と行動が逆。
- **どこか**: §1-4 vs §4表の5行目。
- **何が起きるか**: v7で行末ドット＝アクセント系だった黄の意味が、裁定なしで「音数不一致も含む」に黙って広がる。批判3で問題にされた「印の意味を黙って変える」の形。
- **直し方**: 音数はチップ（あとN音/字余りN）に留め、ドット化は枚2の「印の決まり」に載せて裁定対象にする。

## 5. 「切替オン×帯オフ」の姿が未定義で、裁定11の縦揃えが宙に浮く

- **何が問題か**: §3-1の衝突規則は「イントネーション切替なら高低線とモーラ行は出る」だけで、**メロ帯を含むか書いていない**。§1-2・検証8は「モーラ行は音符と1px以内」を維持するが、音符矩形が畳まれた状態では揃える相手が画面に無い。
- **どこか**: §3-1衝突規則・§1-2・§8-8。枚2・3をどのパーツ状態で描くかは§6にも無い。
- **何が起きるか**: B担当が枚ごとに勝手に決め、枚2と枚3で帯の有無が食い違う（批判2型の枚間不一致）。検証8は対象が定義できず「黙って除外」になる（批判9(b)と同じ仕分けミス）。

## 判定: **直してから**
