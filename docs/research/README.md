## アーカイブ方針＝研究を二度やらないための証跡（2026-07-18 確定）
- **research/ はアーカイブ**。ここに入った調査・実測・サーベイは**上書きで消さない**。更新するときも、決着した過去の文言・出典・数値は**アーカイブとして残す**（追記・追補で積む／古い版は取り消し線や「(旧)」注記で残置し、削除しない）。git 履歴だけに頼らない＝**本文で辿れることが証跡の価値**。
- **なぜ**：研究は再現コストが高い。同じ問いを二度依頼しない／もう一度回さないために、「この問いは**決着済み**（＝到達点）」「この源は**当たり済み**」が README から即引ける状態を保つ。
- **この README が索引＝証跡の入口**：下の **★到達点** と各グループの一覧が「もう答えの出た問い」の目録。**新規 research doc を作ったら README に1行追加**（CLAUDE.md 規約）。再研究を検討する前に、まずここで既決かを確認する。
- **運用 doc との対比**：`docs/design.md`・`docs/backlog.md` は**運用（living）＝今の正準だけを映す**。古くなった記述は**上書き・削除でよい**（過去版の保存先は git 履歴で足りる／本文に旧版を溜めると現況が読みにくい）。＝research だけが in-tree アーカイブ、運用 doc は現況主義、という非対称を意図的に採る。
